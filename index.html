The Architecture — Four Components

1

Theme App Extension — Event Selection UI (2-3 weeks · any plan)

Custom block on the product page: venue selector, date picker, guest counter, tier selector (GA / Gold VIP / Silver VIP / Bronze VIP). Built as a Theme App Extension so it works in the theme editor.

2

Line Item Properties — Event Data Persistence (included in #1 · any plan)

Event details attach as key-value pairs on the line item and persist through checkout. Venue, date, tier, guests — all appear on the order and available via webhooks for fulfillment.

3

Checkout UI Extensions — The Plus Unlock Plus Required

This is where Plus becomes mandatory. Extensions on the information, shipping, and payment steps let them display event details in checkout, add trust messaging ("Official Shoresy Classic ticket"), cross-sell merch, and collect VIP meet & greet names. Without Plus, they cannot customize checkout steps at all.

4

Fulfillment — Ticket Delivery (1-2 weeks · Flow on Plus)

Order webhook fires on payment. Flow automation generates and emails the ticket (PDF, QR code, Apple Wallet). Since NMM is the event provider with no external system to sync, this is the simplest version.

Domain Architecture — No Expansion Stores Needed

Those five domains don't need separate stores. They're front doors to the same building:

letterkenny.tv → Main storefront (all merch, all brands)
shoresyclassic.com → Routes to Shoresy Classic collection/landing page
shoresyclassic.ca / .hockey / .live / .shop → Same store, alternate domains

Same checkout, same customer data, same cross-sell. A fan lands on shoresyclassic.com, buys a ticket, adds a jersey to the same cart, checks out once.

Why Expansion Stores Don't Apply Here

  • Different brand name: "Shoresy Classic" is not "Letterkenny" — expansion stores must be the same brand name
  • Different goods: Event tickets are not merchandise — expansion stores must sell the same goods
  • Same issue for Guns N' Bruno: A whiskey brand also fails the "same name, same goods" test
  • They don't need it anyway: Single-store with collection routing is better — keeps cross-sell in one cart
